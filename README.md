# NorthPeak Digital — Agency Website

A responsive one-page agency site built with **vanilla HTML, CSS, and JavaScript** (no frameworks, no page builders).

## 🔗 Live URL
> Add your Netlify/Vercel/GitHub Pages URL here after deployment

## 📋 Features

### Sections
- **Hero** — Bold headline with CTA, animated stats counter, scroll hint
- **Services** — 6-card responsive grid (Web, SEO, Brand, Ads, Social, CRO)
- **Results** — 3 key metrics + 3 client testimonials
- **Pricing** — 3-tier cards (Starter / Growth / Enterprise)
- **Contact** — Full form with client-side validation

### Technical Highlights
- ✅ Fully responsive at **360px**, **768px**, and **1440px**
- ✅ Vanilla HTML5 / CSS3 / JS — zero dependencies
- ✅ Semantic HTML (header, main, nav, section, article, footer, blockquote)
- ✅ CSS custom properties (design tokens)
- ✅ CSS Grid + Flexbox layouts
- ✅ IntersectionObserver scroll animations
- ✅ Accessible (ARIA labels, focus states, `aria-live` regions)
- ✅ Glassmorphism + gradient design
- ✅ Form validation with real-time feedback

## 🚀 Deployment

### GitHub Pages
```bash
git init
git add .
git commit -m "Initial commit: NorthPeak Digital agency site"
git remote add origin https://github.com/YOUR_USERNAME/northpeak-digital.git
git push -u origin main
# Enable GitHub Pages from Settings > Pages > main branch
```

### Netlify (drag & drop)
1. Go to [netlify.com](https://netlify.com)
2. Drag the project folder onto the dashboard
3. Live in seconds ✅

### Vercel
```bash
npx vercel --prod
```
